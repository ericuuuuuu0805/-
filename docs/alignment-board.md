# 全社目合わせボード（会社課題・体制マッピングの仕組み）

会社としての課題と組織体制（現行＋新規）を1か所にマッピングし、
全社がリアルタイムで「目合わせ」できる仕組み。

## 全体像

```
Notion「🧭 全社目合わせボード」 ←── 全員がリアルタイムに閲覧・編集
 ├── 🔥 課題マップ          … 会社の課題を集約（カテゴリ/優先度/ステータス/担当チーム）
 ├── 🏢 体制マップ          … 現行組織＋立ち上げ中・構想段階の新体制
 └── ✅ 目合わせログ        … 会議で決まったことの記録（背景つき）
        ▲
        │ 毎週月曜 9:00 JST（GitHub Actions）
        │
 scripts/alignment_digest.py
   1. 3つのDBを読み取り、目合わせ待ち／高優先度／停滞課題／共有待ち決定を集計
   2. Claude が全社向け30秒サマリーを生成
   3. ボードの「📬 週次目合わせダイジェスト」セクションを更新
   4. （任意）Slack Webhook に同内容を投稿
```

### 課題マップのステータス設計

- **未着手 → 対応中 → 解決済み** が基本フロー
- **目合わせ待ち** … 全社（または経営）で認識を揃えないと前に進めない課題。
  次回ミーティングのアジェンダとして週次ダイジェストに自動掲載される
- 「最終更新」から **14日以上**更新のない未解決課題は停滞アラートに載る
  （日数は環境変数 `ALIGNMENT_STALE_DAYS` で変更可）

### 体制マップのステータス設計

- **稼働中 / 立ち上げ中 / 構想段階** … 新体制の議論も「構想段階」として先にマップに載せ、
  全社が変化の方向を早く知れるようにする

## 運用ルール

1. 課題は思いついた人がその場で登録する（承認不要）
2. 決定したことは必ず目合わせログに記録し、関連課題のステータスを更新する
3. 目合わせログの「共有ステータス」が「共有待ち」のものは、
   全社に周知したら「全社共有済み」に変更する
4. 週次ダイジェスト（毎週月曜朝に自動更新）を全員が読むことを習慣化する

## セットアップ（GitHub Secrets）

| Secret | 必須 | 用途 |
|---|---|---|
| `NOTION_TOKEN` | ✅ | Notion Integration トークン（既存の週次案件更新と共用） |
| `ANTHROPIC_API_KEY` | ✅ | Claude によるサマリー生成 |
| `SLACK_WEBHOOK_URL` | 任意 | 設定すると Slack にもダイジェストを投稿 |

※ Notion Integration に「全社目合わせボード」ページへのアクセス権を付与すること
（ページ右上「…」→ 接続 → Integration を追加）。

## 手動実行

GitHub → Actions → 「週次 全社目合わせダイジェスト」→ Run workflow。

ローカル実行:

```bash
pip install -r requirements.txt
NOTION_TOKEN=... ANTHROPIC_API_KEY=... python scripts/alignment_digest.py
```
